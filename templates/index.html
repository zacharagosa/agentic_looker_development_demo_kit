1. The Telecom Business Problem & Use Case

The Industry Challenge Reactive Ops

Unscheduled Outages & Heavy SLA Penalties

Zayo operates 5,950+ route miles of mission-critical long-haul dark fiber carrying 464 Tbps of backbone capacity across 8 core transport corridors. Traditional telecom operations are reactive: outages caused by third-party construction backhoe strikes, laser diode degradation, connector dirt, and optical microbends trigger immediate emergency rollouts and severe customer SLA penalty liabilities ($475,000+ exposure).

2. How the BigQuery ML Models are Built

MODEL 1: TIME SERIES 11,712 Rows

Bandwidth Anomaly Engine

route_bandwidth_arima_model

Algorithm: BigQuery ML ARIMA_PLUS time-series forecasting with automated trend, diurnal hourly cycles, and seasonal decomposition.

How It Works: Learns normal diurnal traffic patterns across 8 routes. In production, ML.DETECT_ANOMALIES with 95% confidence intervals flags sudden traffic spikes (DDoS, routing loops) or drops (unannounced fiber degradation).

Materialized Output: route_traffic_anomalies (628 anomalies detected: TRAFFIC_SURGE vs TRAFFIC_DROP).

BQML CREATE MODEL SQL:
CREATE OR REPLACE MODEL `zayo.route_bandwidth_arima`
OPTIONS(model_type='ARIMA_PLUS',
  time_series_timestamp_col='timestamp',
  time_series_data_col='bandwidth_utilization_gbps',
  time_series_id_col='route_id')
AS SELECT timestamp, route_id, bandwidth_utilization_gbps
FROM `zayo.route_traffic_metrics`;
MODEL 2: PHYSICAL LAYER 17,568 Rows

Optical Attenuation Anomaly Engine

optical_attenuation_arima_model

Algorithm: BigQuery ML ARIMA_PLUS on continuous optical loss (attenuation_db_per_km) across 24 fiber spans.

How It Works: Tracks physical layer signal attenuation trends. Flags subtle degradation caused by optical connector contamination, fiber bend stress, or aging splices before bit error rate triggers catastrophic outage.

Materialized Output: optical_span_anomalies (1,756 anomalies classified as CRITICAL_DEGRADATION or ELEVATED_LOSS).

BQML CREATE MODEL SQL:
CREATE OR REPLACE MODEL `zayo.optical_attenuation_arima`
OPTIONS(model_type='ARIMA_PLUS',
  time_series_timestamp_col='timestamp',
  time_series_data_col='attenuation_db_per_km',
  time_series_id_col='span_id')
AS SELECT timestamp, span_id, attenuation_db_per_km
FROM `zayo.optical_span_telemetry`;
MODEL 3: AUTOML PREDICTOR 99.6% Accuracy

Optical Failure & Risk Classifier

automl_optical_failure_classifier

Algorithm: BigQuery ML BOOSTED_TREE_CLASSIFIER (Gradient Boosted Trees / XGBoost) with enable_global_explain=TRUE (Tree SHAP).

Top Feature Importance (SHAP):
• Optical Attenuation: 31.6%
• OSNR Signal-to-Noise: 23.8%
• DAS Acoustic Ground Vibration: 14.5% (detects backhoes digging near fiber!)
• Route Distance: 9.3% | EDFA Laser Output: 7.9%

Performance: 99.6% Accuracy, 0.998 ROC-AUC, 0.995 F1-Score.

BQML CREATE MODEL SQL:
CREATE OR REPLACE MODEL `zayo.automl_failure_clf`
OPTIONS(model_type='BOOSTED_TREE_CLASSIFIER',
  input_label_cols=['failure_risk_label'],
  max_iterations=20, learn_rate=0.1,
  enable_global_explain=TRUE)
AS SELECT failure_risk_label, attenuation_db_per_km,
  osnr_db, pre_fec_ber, edfa_laser_output_power_dbm,
  das_vibration_index, conduit_temp_c, distance_mi
FROM `zayo.optical_span_training_data`;
